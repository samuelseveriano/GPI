# Exemplos da v0.6

Os relatórios desta pasta foram gerados pelo GPI a partir da **base de teste sintética** (`tests/report_fixture.py`).
Por isso todos trazem a faixa e a marca d'água **DEMONSTRAÇÃO**: os números não são dados reais de mercado.
Relatórios gerados com dados reais coletados no CI (sem essa marca) ficam no artefato `validacao-conectores`
do GitHub Actions, pasta `relatorios_reais/`.

As capturas de tela usam a mesma base de demonstração.
