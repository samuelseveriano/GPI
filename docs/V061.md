## 2. Estados das integrações
Configurado (credenciais salvas) → Autenticado (OAuth/chave válidos) → Autorizado (permissões necessárias) →
Validado (consulta real executada) → Funcional (coleta gravada e lida pela aplicação). Também: Restrito
(aguardando aprovação/nível de acesso) e Erro. Uma chave aceita **não** torna a integração funcional.
"Diagnosticar integração" executa testes pequenos (Google Ads: 1 listagem, 1 leitura de conta e 1 consulta com
3 palavras-chave; YouTube: ~102 unidades na primeira execução do dia, pesquisa em cache por 24 h).

## 3. Google Ads — mensagens
| Situação | Mensagem |
|---|---|
| Conta legível, planejador recusado com erro de autorização | Login Google autorizado, mas o projeto ainda não possui acesso Basic necessário para consultar palavras-chave. |
| Lista de contas vazia ou `NOT_ADS_USER` | Conta Google Ads não encontrada. |
| `CLOUD_PROJECT_NOT_APPROVED_FOR_PRODUCTION` (v25+) / `ACTION_NOT_PERMITTED` (v24−) ao ler a conta | Projeto Google Cloud sem autorização para produção. |
| Outros | Autorização de planejamento indisponível (com o código devolvido). |

A API não informa diretamente o nível de acesso do projeto; o GPI deduz pela sequência de chamadas e mostra o código
devolvido. Confirme o nível em Google Cloud Console → Google Ads API → Overview.

## 4. Sincronização
* Ordem de início por prioridade: 1 consumo (Google Ads, Mercado Livre Trends, Microsoft) → 2 tendências → 3
  marketplaces → 4 redes sociais → 5 comércio exterior; fontes independentes continuam em paralelo.
* Fontes sem credencial ou aprovação são resolvidas no início ("Requer autorização"), nunca ficam aguardando.
* Final com falhas parciais: "Sincronização concluída com restrições" (nunca "100% de sucesso").
* Controles: Atualizar fontes, Ver detalhes/progresso, Cancelar (cooperativo: termina a gravação em andamento),
  Tentar novamente fontes com falha, Ver histórico, Exportar diagnóstico.
* Log estruturado por execução em `%LOCALAPPDATA%\GPI\logs\sync\<execução>.jsonl`: fonte, job, endpoint sem
  parâmetros, status HTTP, duração, tentativas, registros e erro. Chaves, tokens e segredos são removidos.
* Exportar diagnóstico: JSON com versões, estado das fontes, integrações (só nomes dos campos configurados),
  histórico, métricas HTTP e eventos recentes — sem credenciais.

## 5. Pendências que dependem do usuário
* Google Ads: projeto Google Cloud com nível **Basic** (ou Standard) para o planejador; não validado sem conta real.
* Meta: corrigir a configuração/estado do app no painel da Meta (lista na Central de Integrações); revisão do app para
  permissões além de public_profile.
* YouTube: o diagnóstico A–E roda com a chave do usuário; a validação real depende dela.
